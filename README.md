### CasaOS moved

The maintained distribution of CasaOS that used to live here is now an organisation of
its own: **[ReCasaOS](https://github.com/ReCasaOS)**.

```bash
curl -fsSL https://github.com/ReCasaOS/CasaOS-Install/releases/latest/download/install.sh | sudo bash
```

The old links still work — GitHub redirects them — but the organisation is the home.
